# 台灣適齡兒童故事與兒歌語料庫建置專案計畫書

**Project Plan: Taiwan Age-Appropriate Children's Story & Nursery Rhymes Corpus (TCCN-Corpus)**

---

## 壹、專案目標

本計畫旨在系統性爬取台灣公開且免費之兒童故事與兒歌資源，透過標準化資料清洗、適齡標籤化與聲韻結構分析，建置一個**「專為 AI 訓練與 RAG 系統設計的結構化兒童語料庫（TCCN-Corpus）」**。此語料庫將作為訓練「適齡兒童故事與兒歌生成系統」的 Few-Shot 範例與微調（Fine-tuning）基底。

---

## 貳、爬取目標與資源庫優先級評估

### 第一級：完全公開與高在地化資源（最優先）

**文化部兒童文化館**
- 核心目標：「繪本花園」動畫劇本與故事大綱；《台灣兒歌一百》得獎作品歌詞（涵蓋國語、台語、客語、原住民語）
- URL：`https://children.moc.gov.tw/`，動畫列表 `/animate_list`，兒歌列表 `/song_list`
- 技術優勢：可優先確認政府資料開放平台是否有 OGD 包

**圓夢繪本資料庫**
- 核心目標：1,400+ 種原創繪本文本、注音拼音、適讀年齡分類，台語/客語配音旁白
- URL：`https://storybook.nlpi.edu.tw`
- 技術優勢：無須登入即可完整閱讀

### 第二級：需借閱權限但語量龐大資源（次優先）

**教育部教育雲電子書整合服務平台**
- 核心目標：30,000+ 本適合國小與學前電子書的書目 metadata、分類、適讀年齡
- 爬取策略：不破解 DRM，僅爬取書目分類、大綱、適讀年齡與跨領域標籤

### 第三級：商業合作與特定格式資源（低度爬取）

**FunPark 童書夢工廠、布克聽聽、親親文化**
- 僅爬取國資圖數位資源入口網上的公開書目、推薦導讀與分類 metadata

## 參、執行階段規劃

### Phase 1：準備與合規審查

- [ ] 各平台 robots.txt 檢測
- [ ] 確認文化部 OGD 資料介接接口
- [ ] **建立合規矩陣（來源 × 用途 × 授權）**（見 `docs/data-sources.md`）
- [ ] 定義並鎖定 `schemas/corpus_schema.json`
- [ ] 確立法律邊界與資料下載授權鏈
- [ ] 輸出：Phase 1 可行性評估報告

### Phase 2：爬蟲腳本開發與測試

- [ ] 編寫 Scrapy（文化部）爬蟲
- [ ] 編寫 Playwright（圓夢繪本）爬蟲
- [ ] 測試動態翻頁與「文字隱藏/顯示」擷取率
- [ ] 爬蟲輸出直接對齊 `corpus_schema.json` raw 欄位
- [ ] 輸出：爬取可行性評估報告（含預估筆數）

### Phase 3：全面爬取與影音分離

- [ ] 執行分散式爬取，繪本文本、兒歌歌詞存入數據湖（`data/raw/`）
- [ ] （選做）下載免費兒歌 MP3，使用 Whisper 進行台語/國語語音對齊
  > ⚠️ 注意：Whisper 台語 WER 偏高，結果存獨立欄位 `audio_transcript`，不污染主文本

### Phase 4：資料清洗與幼教標籤化

- [ ] NLP 欄位清洗，去除雜訊字元
- [ ] 執行自動標籤 Pipeline：0~6 歲語言里程碑對齊、兒歌聲韻規則標記
- [ ] 輸出存入 `data/labeled/`

### Phase 5：向量資料庫（RAG）建置

- [ ] 結構化文本轉 Vector Embeddings
- [ ] 建置向量資料庫（初期：Pinecone Starter；量產後評估 Milvus）
- [ ] Metadata 篩選欄位：適讀年齡、主題、語言、動作指示

### Phase 6：系統測試與 Prompt 優化

- [ ] 語料庫作為 Few-Shot 範例，注入限制條件 Prompt 系統
- [ ] 生成測試：評估適齡精準度與聲韻合規度

## 肆、預期交付成果

1. **TCCN-Dataset（JSONL 格式）**：至少 1,500 筆清洗完畢、標註注音、年齡層與動作指示的台灣在地化繪本故事與兒歌語料
2. **RAG 向量檢索模組**：可依複合條件（如「3-5 歲、克服黑暗、台語、手部細動作」）即時檢索最貼切的 3 筆真實繪本大綱作為 Few-Shot 引導
3. **合規性稽核報告**：詳列爬取來源、下載範圍及不涉及侵權之技術隔離防護措施說明書
